# exp2

Updated to expand the number of categories as well as pre-generate the novel choice trials to have more divergent trials.

To install dependencies:

```bash
bun install
```

To build experiment for use in cognition.run:

```bash
bun run build
```

To simulate data with the experiment:

```bash
bun --preload ./setup.js simulate.js
```

This project was created using `bun init` in bun v1.0.0. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
