# De-identified data

Generated by `pixi run python -m cactus_paper.data.deidentify` from the local (gitignored)
`data/raw/` and `data/processed/`. Do not edit by hand; rerun the script.

- `raw/exp1/continuous-attribute-choice-task.csv.gz` — Experiment 1 platform export (SONA sample)
- `raw/exp2/cactus-v2.csv.gz` — Experiment 2 platform export (Prolific sample)
- `processed/exp{1,2}/*.csv.gz` — trial-level tables the analyses read
  (exp2 `processed/` is reproduced exactly by `cactus_paper.data.process_raw` run on `raw/exp2`)

Participants are keyed by `run_id`, the platform's sequential run number. Removed: Prolific
PID / study / session IDs, SONA IDs, IP, user agent, referer URL, browser / OS, accept-language,
demographics and medical-history responses, free-text debrief answers (the input-device answer
is kept), and the Prolific completion code. `recorded_at` is reduced to the date.

pandas reads the `.csv.gz` files directly: `pd.read_csv("data/shared/processed/exp2/choice_data.csv.gz", index_col=0)`.
